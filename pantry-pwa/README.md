# 🧺 Pantry Stock Tracker — PWA

A mobile app to track food stock, expiry dates, and get daily alerts.

---

## 📱 How to Deploy FREE & Install on Your Phone

### Option 1: Netlify (Recommended — 100% Free)

1. Go to **netlify.com** → Sign up free with GitHub/email
2. Click **"Add new site" → "Deploy manually"**
3. Drag and drop the **entire `public/` folder** into the deploy box
4. Done! You get a URL like `https://your-pantry.netlify.app`

**Install on Android:**
- Open the URL in Chrome
- Tap the menu (⋮) → "Add to Home screen"
- It installs like a real app!

**Install on iPhone:**
- Open the URL in Safari
- Tap Share (□↑) → "Add to Home Screen"
- Done!

---

### Option 2: GitHub Pages (Also Free)

1. Create a free account at **github.com**
2. Create a new repository (e.g. `pantry-app`)
3. Upload everything inside the `public/` folder to the repo
4. Go to Settings → Pages → Source: `main` branch → `/root`
5. Your app lives at `https://yourusername.github.io/pantry-app`

---

### Option 3: Vercel (Free)

1. Go to **vercel.com** → Sign up free
2. Click "Add New → Project"
3. Import from GitHub (after pushing `public/` folder)
4. Set Output Directory to `public`
5. Deploy!

---

## ✅ Features

- 📦 Add/edit/remove items with quantity, unit, category
- 📅 Expiry date tracking with color-coded status
- 🔔 Browser push notifications for expired/expiring items
- 📍 Location filter: Room, Kitchen, Fridge, Freezer
- 🔍 Search items instantly
- 📊 Live stats dashboard
- 💾 Data saved locally on your device (no server needed)
- 📱 Installable on Android & iPhone (PWA)
- ✈️ Works offline after first visit

---

## 💡 Tips

- Enable notifications when prompted for daily expiry alerts
- Data is stored on YOUR device — private & free forever
