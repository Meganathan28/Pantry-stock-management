# 🥫 Pantry Stock Tracker

A sleek and responsive pantry stock management Progressive Web App (PWA) built for everyday household inventory tracking.

Track groceries, monitor expiry dates, organize pantry items, and receive expiry alerts — all in a fast, lightweight, mobile-friendly interface.

Built as a real-world productivity tool and portfolio project using modern frontend practices.

---

## ✨ Features

- 📦 Add, edit, and remove pantry items
- 📅 Expiry date tracking
- ⚠️ Expiring & expired item alerts
- 🔔 Daily notification reminders
- 🔍 Real-time search functionality
- 🏷️ Category-based organization
- 📍 Storage location tracking
- 📊 Inventory statistics dashboard
- 📱 Fully responsive mobile-first UI
- 🌙 Modern dark-themed interface
- ⚡ Offline-ready Progressive Web App (PWA)

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Meganathan28/pantry-stock-tracker.git
```

### Navigate to the Project Directory

```bash
cd pantry-stock-tracker
```

### Run Locally

Since this is a lightweight frontend application, simply open:

```bash
index.html
```

Or use a local development server:

```bash
npx serve
```
